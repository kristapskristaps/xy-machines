# Beaver drummer

The display uses the layered vector scene generated by `python artwork/beaver.py`.
It preserves the shared control header and all 18 drum emblems, placing the
selected emblem on the front kick head like a band's logo. The generated pose
table keeps each head/arm/stick/kit layer attached to the same local pivot.
The contact table solves each shoulder–paw–stick chain against its playing
surface. Independent shoulder and wrist springs provide follow-through;
forward kinematics keeps the stick at the paw throughout its rebound.

A concept was developed with the built-in image-generation tool: a confident
beaver in angular sunglasses, with visible front teeth and a paddle tail,
playing a compact vintage drum kit; black background, clean cream contours,
electric-blue and vermilion accents, blank kick head, no lettering or UI.
The production scene is original vector artwork, with no raster dependency.
