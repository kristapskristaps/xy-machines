# Halo DSP provenance

Halo is an original integrated effect adapted from the PunchKit Space processor,
Copyright (c) 2026 Kristaps Dreija. The source repository and this adaptation are
proprietary; see LICENSE. No Teenage Engineering firmware, artwork or algorithm
implementation is included. Mother is a sonic reference, not a claimed emulation.

Reference: `punchkit-ios/EP133Manager/Sources/EP133App/RecorderSpaceEffects.swift`
from repository commit `f95f7e8be3d2105ae0e902c549dd51ea7d06e7b2`.
SHA-256 of the referenced file: `fa2914b82e11ad7d02a6794a6981eb110986671993215e7852de07e971ce5078`.

The figure-eight plate topology, asymmetric delay times, input diffusion,
two-head Hann-windowed octave shift, filtered echo feedback and transient bloom
follow that processor. Halo combines them in one stereo network with its own
controls and gain structure. Room size uses one smoothly moving fractional tap per stage to preserve feedback energy, replacing the reference processor's two-size crossfade. The floating-point implementation is rewritten as
bounded fixed-point C++ using public Open-XY SDK arithmetic. Long echo storage
is stereo 16-bit with quantization-error feedback. Reverb and shimmer storage
use Q24 words. The wet network runs at 11.025 kHz behind two cascaded 31-tap halfband conversion stages;
delay lengths, modulation and smoothing are retimed, and Color is limited to 4 kHz. The native callback and browser interface run at 44.1 kHz. Hold removes new input
and pitched recirculation while preserving the unpitched reverb feedback.

Tables are generated by tools/generate_tables.py from standard mathematical
formulas. The Open-XY SDK is a separate dependency under its own licence.
